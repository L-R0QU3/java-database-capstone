# SmartCare Clinic Management System

Capstone Project - IBM Java Developer Professional Certificate

## Overview
A full-stack clinic management system built with Spring Boot, MySQL, MongoDB, and Docker.

## Architecture
See [docs/architecture.md](docs/architecture.md) for the architecture design document.

## Tech Stack
- Java 17
- Spring Boot 3
- Spring MVC + Thymeleaf
- Spring Data JPA + Hibernate
- MySQL + MongoDB
- JWT Authentication
- Docker
- GitHub Actions (CI/CD)
